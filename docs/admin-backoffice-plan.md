# 博客后台系统建设计划（审阅版 v1.0）

文档日期：2026-02-13  
适用项目：`vue-blog-single-store`

## 1. 项目目标

- 建立独立后台，支持“几乎可修改前台全部内容”的配置与发布。
- 提供全面数据看板，便于快速查看趋势、异常和运营效果。
- 支持完整增删改查与批量操作，缩短操作路径。
- 优先优化手机端适配，保证移动端可完成核心管理流程。

## 2. 建设范围

首期包含：

- 仪表盘（数据总览）
- 内容管理（文章/标签/分类）
- 页面与站点配置（首页模块、导航、关于、友链、页脚）
- 评论管理（审核/屏蔽/置顶）
- 发布与回滚（草稿/发布）
- 主题配置（设计 Token）
- 权限与角色
- 操作日志
- 移动端深度适配

首期不包含（后续迭代）：

- 多租户
- 复杂审批流
- 多语言翻译平台

## 3. 总体架构

- 前端：独立 `Admin` 应用（Vue3 + TypeScript + Vite + Pinia + Vue Router）
- 后端：REST API（后续可扩展 GraphQL）
- 数据层：PostgreSQL + Redis + 对象存储（图片/附件）
- 发布模型：草稿/发布双态，支持预览链接与版本回滚

## 4. 功能模块清单

## 4.1 仪表盘

- 核心指标：PV、UV、发文数、评论数、错误数
- 趋势图：7/30 天趋势
- 热门榜：热门文章、热门标签、热门来源
- 系统监控：API 耗时、失败率、慢查询数量

## 4.2 内容管理

- 文章：新增/编辑/删除/发布/下线
- 分类：增删改 + 文章归类
- 标签：增删改 + 使用计数
- 搜索筛选：关键字、分类、标签、状态、时间范围
- 批量操作：批量发布、批量下线、批量删除

## 4.3 页面与站点配置

- 站点资料：名称、签名、头像、社交链接
- 导航配置：菜单项排序、显隐、跳转规则
- 首页模块：模块启用/禁用、顺序、数据源
- 关于页配置：区块增删改排序
- 友链配置：增删改、标签管理
- 页脚配置：备案信息、运行信息、版权

## 4.4 评论管理

- 评论列表：按文章、时间、状态筛选
- 审核状态：通过/待审/拒绝
- 批量处理：批量通过、批量隐藏、批量删除
- 规则能力：敏感词与频控策略预留

## 4.5 主题与视觉配置

- 设计 Token 编辑：颜色、字体、间距、圆角、阴影
- 动效策略：动画强度、过渡时长、低动效模式
- 实时预览：后台配置后可预览前台效果
- 一键回退：恢复最近稳定主题版本

## 4.6 发布中心

- 草稿保存
- 预览链接生成
- 正式发布
- 版本回滚
- 发布记录追踪（谁、何时、改了什么）

## 4.7 权限与安全

- 角色：管理员 / 编辑 / 运营 / 只读
- 菜单权限与接口权限映射
- 关键写操作审计日志
- 登录态与会话管理（支持 token 刷新）

## 5. 移动端优先适配策略

- Mobile First 布局，桌面端增强
- 底部主导航 + 顶部上下文操作
- 表格在手机端切换为卡片列表
- 表单分步编辑 + 自动保存草稿
- 固定底部操作栏（保存/发布）
- 图表可横向滑动并支持指标折叠

性能目标（手机端）：

- 首屏可交互 < 2.5s（中端机 + 4G）
- 核心页面 FPS 保持流畅，减少重排与大面积重绘

## 6. 接口与数据计划

第一阶段复用现有接口契约：

- `GET /blog/bootstrap`
- `POST /blog/posts`
- `PUT /blog/posts/{postId}`
- `DELETE /blog/posts/{postId}`
- `POST /blog/posts/{postId}/comments`
- `PATCH /blog/posts/{postId}/comments/{commentId}/like`
- `PATCH /blog/site/profile`
- `PATCH /blog/site/footer`
- `PUT /blog/site/links`
- `PUT /blog/site/about`
- `PUT /blog/site/projects`

第二阶段新增后台专用接口：

- `POST /admin/auth/login`
- `POST /admin/auth/refresh`
- `POST /admin/auth/logout`
- `GET /admin/dashboard/overview`
- `GET /admin/audit-logs`
- `POST /admin/media/upload`
- `GET /admin/media/list`
- `PUT /admin/theme/config`
- `POST /admin/publish/preview`
- `POST /admin/publish/commit`
- `POST /admin/publish/rollback`

## 7. 分阶段排期（建议）

1. 阶段 A（1 周）：后台骨架、登录鉴权、权限基础、移动端导航框架  
2. 阶段 B（1.5 周）：文章/分类/标签/评论 CRUD + 批量操作  
3. 阶段 C（1 周）：站点配置与页面模块配置（覆盖前台主要可改项）  
4. 阶段 D（1 周）：主题 Token 编辑、实时预览、发布与回滚  
5. 阶段 E（1 周）：仪表盘、操作日志、告警基础  
6. 阶段 F（1 周）：移动端深度优化、性能压测、可用性测试、上线文档

## 8. 验收标准

- 手机端可完成：发文、改导航、改首页模块、改主题、审核评论、发布回滚
- 后台 90% 高频操作在 3 步内完成
- 所有关键写操作具备审计记录
- 发布失败可回滚，回滚后前台一致
- 接口错误可通过 `requestId` 定位

## 9. 风险与控制

- 需求膨胀：以可用闭环优先，复杂功能后置
- 配置错误影响前台：配置 Schema 校验 + 发布前检查
- 移动端表单复杂：分步流程 + 自动保存 + 固定操作栏
- 数据一致性：事务写入 + 发布快照 + 回滚

## 10. 里程碑产出物

- `M1`：后台基础框架与权限体系
- `M2`：内容管理与评论管理可上线
- `M3`：站点与页面配置可覆盖前台主体内容
- `M4`：主题系统 + 发布回滚可用
- `M5`：仪表盘与日志系统可用
- `M6`：移动端体验达标并完成上线交付

## 12. 实施进展（2026-02-14）

已落地（当前可用）：

- 后台登录链路：`login / refresh / logout`、权限路由守卫、接口权限校验。
- 仪表盘：总览指标、趋势、热门内容、系统状态。
- 内容管理：文章增删改查、筛选、批量操作。
- 内容编辑增强：结构化编辑 + Markdown 双模式、编辑器内实时预览、媒体库选图插入、标签管理（批量加标签/全局重命名/全局删除）。
- 站点配置：资料、页脚、友链、关于、项目配置可直接驱动前台展示。
- 评论管理：筛选、状态变更、删除与批量处理。
- 主题管理：Token 版本管理、激活切换。
- 发布中心：预览链接、正式发布、版本回滚、发布记录。
- 媒体库：外链录入 + 本地图片上传 + MinIO 签名直传/分片上传，支持跨存储统一清理（local + MinIO + 孤儿分片中止）。
- 数据模型迁移：媒体域、博客内容域、后台运行态均已切换到领域表主读（保留快照兜底与兼容回填）。
- 发布收尾能力：已提供发布前检查脚本（质量门禁 + 运行态一致性 + 回滚目标校验）与 MinIO 生命周期策略脚本。
- 角色权限：用户角色/权限编辑、禁用状态管理。
- 操作日志：关键写操作审计记录与查询。
- 移动端管理体验：抽屉导航、卡片化操作、固定底部动作栏。
- 工程门禁：`yarn quality-gate` 已接入 CI，包含契约漂移与安全基线检查。

当前差距与下一批建议：

1. 仓库治理收尾：将 `Quality Gate` 真正设置为 required status check（仓库设置层动作）。
2. 发布中心仍缺变更 Diff 视图（当前已具备 preflight 与回滚校验脚本）。
3. 权限域仍需补齐成员邀请、密码重置、双因素认证等账号安全能力。
4. 后台站点配置写接口仍部分复用 `/api/blog/site/*`，下一步可补齐 `/api/admin/site/*` 聚合管理接口。
