# Mobile Checklist

## Layout

- Use single-column structure by default.
- Prevent horizontal overflow and clipped text.
- Keep primary actions reachable with one thumb.

## Interaction

- Keep touch targets at practical minimum size.
- Keep destructive actions separated from primary actions.
- Keep loading and disabled states explicit.

## Reliability

- Validate keyboard overlap for form inputs.
- Validate safe-area behavior on iOS and Android.
- Validate performance on mid-range devices.
