# Critical Task Flows

## Flow: Edit and Publish Post

- Open post editor
- Modify content
- Save draft
- Preview changes
- Publish

## Flow: Moderate Comments

- Filter comments
- Select target comments
- Apply batch status update
- Verify updated state

## Flow: Rollback Release

- Open publish history
- Select rollback target
- Enter rollback reason
- Execute rollback
- Verify key pages
